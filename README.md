# Simple To-Do List

## Description

This is a simple To-Do List made using HTML, CSS, and JavaScript.

The user can add tasks and delete tasks from the list.

## Features

- Add a task
- Display tasks
- Delete tasks
- Simple and easy-to-use design

## Technologies Used

- HTML
- CSS
- JavaScript
